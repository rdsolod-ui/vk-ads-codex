# vk-ads-codex

Исследование и работа с VK Рекламой: кабинеты, кампании, группы, объявления, аудитории, аналитика, каталоги, API и интеграции. Используйте для технических задач VK Ads с проверкой актуальной документации.

Общий устанавливаемый навык Codex на русском языке. Независимый проект, не официальный продукт VK. Исследование: 2026-09-09. Версия: 1.0.0. Лицензия MIT относится к оригинальному коду и методике; права на материалы и марки VK принадлежат их владельцам. Полные копии документации и данные рекламного кабинета в пакет не включены.

## Установка

```sh
npx --yes skills add rdsolod-ui/vk-ads-codex --skill vk-ads-codex --agent codex --global --copy --yes
```

Или через штатный установщик Codex с фиксацией версии:

```sh
python /path/to/skill-installer/scripts/install-skill-from-github.py --repo rdsolod-ui/vk-ads-codex --path skills/vk-ads-codex --ref v1.0.0
```

После установки навык доступен со следующего хода. Вызов: `$vk-ads-codex`. Навык также допускает автоматический выбор. Обновление существующей установки выполняйте с резервной копией и проверкой версии, не удаляя её вслепую.

## Использование

«Используй $vk-ads-codex: проверь задачу VK Ads по актуальной справке и предложи проверяемое решение».

Начните с [SKILL.md](skills/vk-ads-codex/SKILL.md). Примеры являются учебными; суммы, контакты, промокоды и права на награду не подтверждаются самим примером. Все рекомендации по игровой подаче отделены от технических требований VK. Навык не требует остальных четырёх пакетов, но может использоваться вместе с ними.

## Проверка

```sh
python scripts/validate_package.py
python -m unittest discover -s tests -v
```

Проверки офлайн не заменяют предпросмотр, проверку кабинета, фактическую выдачу награды и модерацию. См. [CHANGELOG](CHANGELOG.md) и [SECURITY](SECURITY.md).
