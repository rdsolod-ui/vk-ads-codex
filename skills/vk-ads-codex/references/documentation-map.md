# Карта официальной документации

Проверка: 2026-09-09. Охват индексов [справки](https://ads.vk.ru/help) и [API](https://ads.vk.ru/doc/api) представлен в `sources.json`: URL, название, способ получения, статус и дата. Статус `retrieved` означает получение текста, а не ручное тестирование каждого метода. Углублённый разбор выполнен для рекламодательского кабинета, создания/изменения рекламы, измерения, лид-форм, авторизации и структуры API. Партнёрские SDK, отраслевые фиды, акции и мобильные сценарии каталогизированы для чтения по запросу. Не называйте карту исчерпывающим независимым аудитом всех функций.

| Задача | Отправная точка | Что проверить |
|---|---|---|
| Вход, тип аккаунта, агентство | [Авторизация](https://ads.vk.ru/help/authorization) | текущий субъект, роли, клиент, доступ к объектам |
| Кампания / группа / объявление | [Этапы создания](https://ads.vk.ru/help/general/start/creating) | цель, рекламируемый объект, уровень бюджета, статус и расписание |
| Медиа и форматы | [Форматы](https://ads.vk.ru/help/features/formats) | объект × формат × размещение, технические ограничения |
| Ставки и бюджет | [Стратегии](https://ads.vk.ru/help/features/bid_strategy), [оптимизация](https://ads.vk.ru/help/features/optimization) | где задан бюджет, модель оплаты, обучение, лимиты |
| Аудитории | [Аудитории и списки](https://ads.vk.ru/help/features/audiences_lists) | источник, включения/исключения, расширение, доступ |
| Сайт и события | [Пиксель](https://ads.vk.ru/help/general/sites/pixel) | домен, событие, момент срабатывания, диагностика |
| Атрибуция | [Сайт](https://ads.vk.ru/help/general/sites/site_attribution) | post-click/post-view отдельно от времени атрибуции API |
| Каталоги | [Центр коммерции](https://ads.vk.ru/help/general/ecomm/ecomm_interface) | спецификация категории, feed, группы товаров, ошибки, события |
| Мобильные приложения | [Приложения](https://ads.vk.ru/help/general/apps) | магазин, MMP, postback, deeplink, схема атрибуции |
| Лид-формы | [Создание](https://ads.vk.ru/help/general/lead_forms/lead_forms) | четыре шага, зависимости, контакты, результат |
| Статистика и финансы | [Раздел](https://ads.vk.ru/help/statistics) | период, метрики, валюта, расход и пополнение отдельно |
| Модерация и документы | [Модерация](https://ads.vk.ru/help/documents/moderation) | причина, подтверждающие документы, текущие правила |
| ОРД | [Маркировка](https://ads.vk.ru/help/ord) | тип участника, реквизиты, договоры/акты, статус, ERID |
| Мобильный кабинет | [Раздел](https://ads.vk.ru/help/mini_ads) | возможности упрощённого интерфейса, не приравнивать к полному |
| Монетизация | [Кабинет партнёра](https://ads.vk.ru/help/partner) | площадка, SDK, privacy, ads.txt; это отдельный контур |

Для API ищите раздельно `info` (поведение), `resource` (HTTP-операция) и `object` (поля). Прочтение только имени метода не подтверждает его контракт. Полные сторонние зеркала не используются как источник истины.

[Указатель HTTP-ресурсов](api-resource-index.md) помогает выбрать нужный метод без переноса полного текста документации.
