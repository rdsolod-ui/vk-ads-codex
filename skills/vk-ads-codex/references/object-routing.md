# Маршрутизация по рекламному объекту

Сначала выберите рекламируемый объект и доступную цель, затем формат/размещение. Фид, лид-форма и пиксель — разные сущности; одна не заменяет другую.

| Контур | Техническое решение и проверка |
|---|---|
| Сайт | [Pixel](https://ads.vk.ru/help/general/sites/pixel): правильный домен и событие, загрузка, отладка, совпадение UI с фактом; [UTM](https://ads.vk.ru/help/features/utm): макросы, кодирование, отсутствие секретов, сохранение через редирект |
| Каталог | [Требования](https://ads.vk.ru/help/general/ecomm/feed_catalog/ecomm_catalog_requirements): выбрать отраслевую спецификацию; проверить URL фида, устойчивые item IDs, цену/наличие, доступность изображений, группу товаров, диагностику; для ретаргетинга сопоставить item IDs событий и каталога |
| Сообщество и пост | [Сообщество](https://ads.vk.ru/help/general/community/engagement): права, точная ссылка, доступность поста, целевое действие; не переносить ограничения сайта на пост |
| Мини-приложения | [Mini Apps](https://ads.vk.ru/help/general/network/mini_app): проверить объект, события и placement; бот/рассылка и встроенная лид-форма не равнозначны |
| Приложение | [MMP](https://ads.vk.ru/help/general/apps/integration_tracker): магазин, tracker, разрешённые события, postback, deeplink и окно атрибуции; device/OS ограничения читать в текущей схеме |
| Аудитории | [Списки](https://ads.vk.ru/help/features/audiences_lists/user_lists): допустимый формат/источник и правомерность данных; [look-alike](https://ads.vk.ru/help/features/audiences_lists/look_alike): качество исходной выборки; уточнить расширение и исключения |
| Опрос / Brand Lift | [Опросы](https://ads.vk.ru/help/general/lead_forms/surveys), [Brand Lift](https://ads.vk.ru/help/general/lead_forms/brand_lift): отдельные объекты, поля и методология; условие Survey не доказывает ветвление LeadForm |
| Модерация | [Правила и документы](https://ads.vk.ru/help/documents): сохраните точную причину, сравните текст/медиа/посадку, исправляйте конкретный дефект; отправка на модерацию не гарантирует одобрения |
| ОРД | [ORD](https://ads.vk.ru/help/ord): используйте схему своего типа участника, проверьте данные клиента, токен ERID, акты и статусы; не отправляйте юридические данные на основе выдуманных реквизитов |
| Партнёрская монетизация | [Partner](https://ads.vk.ru/help/partner): SDK/Web/ads.txt и выплаты — отдельный контур от покупки рекламы; находите точную платформу и версию через sources.json |

Универсальные объявления: заголовок 40, краткий текст 90, рядом с кнопкой 30 — только когда соответствующая роль доступна. PNG/JPG до 5 МБ; рекламные изображения 1:1 (600×600), 4:5 (1080×1350), 16:9 (1080×607). Это не универсальная матрица всех продуктов: карусели, лендинги и видео имеют собственные ограничения. [Полная актуальная справка форматов](https://ads.vk.ru/help/features/formats).
