# Безопасность и данные

Не прикладывайте к публичным issues токены, cookies, webhook URL с секретами, персональные данные лидов, дампы кабинета или приватные скриншоты. Для воспроизведения используйте синтетические примеры и обезличенные ошибки. Не публикуйте найденный секрет; передайте владельцу приватным способом, который он подтвердил.

Этот пакет не содержит учётных данных и не авторизует внешние действия. Локальные JSON-спецификации могут содержать данные пользователя; храните их вне публичного репозитория. Проверки выполняются локально и ничего не отправляют в VK.
